# Casa Acaiúba — English menu

Site estático com as 6 páginas originais do PDF, pronto para o GitHub Pages.

## Publicar

1. Crie um repositório no GitHub, por exemplo `cardapio-casa-acaiuba`.
2. Envie **o conteúdo desta pasta** (`index.html` e a pasta `assets`) para a raiz do repositório. Não envie apenas o arquivo HTML: ele precisa das imagens.
3. No repositório, entre em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**; selecione **main** e **/(root)** e salve.
5. Aguarde o GitHub informar o endereço publicado, normalmente `https://SEU-USUARIO.github.io/cardapio-casa-acaiuba/`.

Funciona sem banco de dados, bibliotecas externas ou servidor. As setas, os pontos, o teclado e o gesto de deslizar navegam entre as páginas. Toque na imagem para abri-la em resolução maior.
